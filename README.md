# COS 201 - Computer Programming I
## Week 3 Java Programs

This repository contains three beginner Java programs:

1. **SimpleCalculator.java** - Performs addition, subtraction, multiplication and division.
2. **AverageCalculator.java** - Calculates the average of numbers entered by the user.
3. **ItemCost.java** - Calculates the total cost from an item's quantity and unit price.

## Requirements
- Java Development Kit (JDK) installed.
- A terminal or command prompt.

## How to compile and run

Open a terminal in the folder containing the Java files.

### SimpleCalculator
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

### AverageCalculator
```bash
javac AverageCalculator.java
java AverageCalculator
```

### ItemCost
```bash
javac ItemCost.java
java ItemCost
```

## Notes
- Enter numeric values when the program requests numbers.
- The calculator does not allow division by zero.
- The average calculator requires the number of values to be greater than zero.
- The item cost calculator does not accept negative quantity or unit price.
